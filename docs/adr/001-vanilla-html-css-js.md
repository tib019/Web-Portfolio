# ADR-001: Vanilla HTML/CSS/JavaScript für Portfolio

**Status:** Accepted  
**Datum:** 2025

## Kontext
Ein persönliches Web-Portfolio für Tobias Buß soll Kenntnisse und Projekte präsentieren.

## Entscheidung
Vanilla HTML, CSS und JavaScript ohne Framework — bewührter Stack für statische Portfolio-Seiten.

## Abgewogene Alternativen
- **React/Next.js:** Überdimensioniert für ein persönliches Portfolio
- **Jekyll/Hugo:** Static Site Generators, aber zusätzliche Abhängigkeiten
- **WordPress:** Zu viel Overhead und Sicherheitsrisiken

## Konsequenzen
**Positiv:**
- Maximale Kontrolle über HTML/CSS
- Kein Build-Schritt nötig
- Zeigt Grundkenntnisse in reinem Web-Development

**Negativ:**
- Kein State Management für komplexere Interaktionen
- Wartung bei Erweiterungen manueller
