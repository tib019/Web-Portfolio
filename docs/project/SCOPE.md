# Projektscope — Web-Portfolio

## Problem
Als Fachinformatiker Anwendungsentwicklung benötigt Tobias Buß ein professionelles Online-Portfolio, um Projekte, Fähigkeiten und Kontaktmöglichkeiten zu präsentieren.

## Lösung
Statische Portfolio-Website mit Vanilla HTML/CSS/JS, inklusive Projektpresentationen, Lebenslauf-Elementen und Kontaktformular.

## In Scope
- Persönliche Präsentation (Skills, Projekte, Werdegang)
- Responsive Design
- Projekt-Übersicht mit Links zu GitHub-Repos
- Kontaktmöglichkeiten (E-Mail, LinkedIn, GitHub)
- Interaktive Elemente (JavaScript-Spielchen im `game.html`)
- Kurs-Übersicht (`GfnKurse.html`)
- Node.js Server für lokale Entwicklung

## Out of Scope
- Blog/CMS-Funktionalität
- User-Login
- Bezahlte Dienste oder E-Commerce

## Technologie-Stack
| Schicht | Technologie |
|---------|-------------|
| Markup | HTML5 |
| Styling | CSS3 |
| Interaktivität | Vanilla JavaScript |
| Server (Dev) | Node.js |
| Tests | Playwright |
